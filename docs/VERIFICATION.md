1. 使用提供的管理账号完成 OpenList 登录，确认管理员角色与根基础路径；没有修改原站登录配置。
2. 读取根目录和挂载，访问实际原文件管理前端；确认自定义增强脚本不会产生页面脚本异常。
3. 创建独立、随机后缀的 `OpenList-AI-verification-*` 测试目录，上传 5,097 字节 / 4 秒 MP4。视频由明确可控的房屋、草地、天空、太阳画面生成，**不是对用户既有长视频的准确率评估**。
4. 上传后回读 OpenList 文件，确认大小和存在性。媒体源为真实网盘下载域名，没有使用本地文件路径绕过网盘读取。
5. 从插件 API 启动实际目录扫描，持久化任务，远程网盘读取并抽取 `0.5, 1.5, 2.5, 3.5` 秒画面，调用官方 MiniCPM-V 4.7 1B。
6. 模型返回中文摘要及“房屋、草地、天空、太阳”标签；识别任务完成，SQLite 保存采样点、时长、模型与媒体转发字节。本次累计转发 25,485 字节（探测和多次抽帧会重复读取小文件）。
7. 原 OpenList 列表直接出现真实结果；实际网格同样显示标签；原右键菜单中出现 AI 结果 / 识别 / 编辑操作，原下载、重命名等项保留。

实际重新识别标签会有轻微措辞变化，例如出现“光源”，不能据此宣称确定性或普遍准确率。可在原界面继续用自己的视频验证。

- HLS / DRM / 直播、音频转写、自适应镜头切分、用户共享链接、分布式队列、自动历史清理不在首版实现中。

- 首轮没有远程服务器 Shell，仅提供本机网关。随后用户提供 SSH，已在 Serv00 安装无 Docker 伴随服务、独立 nginx、daemon 与 cron；真实网盘抽帧通过，但国内模型 API 从该主机连接超时，海外入口不接受国内密钥。**公网原站尚未切换，也没有注入原站脚本，远程在线识别尚未验收。** 最新状态见 [FreeBSD 部署记录](FREEBSD.md)。
