# 用户操作与故障排查

## 后台管理

使用 OpenList 管理员账号进入 `/@manage`，点击侧栏的「AI 视频标签」。手机可点击后台顶部同名按钮，或从侧栏进入。

也可直接打开 `/@manage?ai=video-tags`。管理选项显示在原后台内容区，支持刷新、浏览器前进后退和浅色 / 深色模式。

- 「模型与扫描配置」：模型地址与规格、密钥更新、连接测试、目录与排除项、格式、定时扫描、并发和流量限制，以及数据备份下载。
- 「识别任务」：查看进度，扫描所有已配置目录，暂停、恢复、取消或重试失败任务。
- 「标签规则」：管理同义标签和常用标签。
- 「历史与错误日志」：查看识别及错误记录。

普通账号不显示这些管理入口，管理 API 也会检查管理员权限。已有模型密钥不会回传；填写的新密钥保存后立即生效。退出或切换登录会话会清除插件管理表单。原有存储、用户和个人资料页面仍从原侧栏进入。

## 扫描与标签

管理员进入 `/@manage` →「AI 视频标签」，在模型与扫描配置中填写目标目录，再从「识别任务」启动扫描。首页和目录页不再显示插件管理栏。任务面板按扫描批次显示等待、识别中、成功和失败数量；目录发现和模型识别并行进行，所以扫描前期总数会增长。

暂停停止领取新目录 / 视频，已经领取的任务可能完成当前页或当前视频。恢复继续处理。取消会阻止正在执行的模型结果写入；已经发出的模型请求不保证免计费。取消后的批次不可恢复，可重新发起扫描；已有成功视频会跳过。

识别失败后，任务面板“重试失败任务”重新入队。若源视频已变化，应先重新扫描获取新指纹；对单个视频可直接点“重新识别”。

列表、网格和图片三种视图都通过小型 AI 状态标记展示识别入口，不再增加文件行高。鼠标移到视频上显示悬浮卡片，手机点击 AI 标记查看；键盘聚焦标记也会显示，按向下键可进入卡片操作，Esc 关闭。卡片包含识别状态、简介、全部标签和完整结果入口；长简介可展开，人工标签使用不同颜色。点击标签进入原生搜索，点击原文件仍正常打开视频。

插件不强制切换文件视图，也不修改 OpenList 全局默认设置。OpenList 优先使用当前目录记住的视图，再使用全局默认；即使全局默认为列表，曾选择网格的目录仍可显示网格。要修改该目录，使用右上角视图按钮选择列表。AI 信息在三种视图里均以悬浮卡片展示。图片视图原本不展示视频，插件复用原目录请求的数据补充视频卡片；缩略图使用 OpenList 已提供的缩略图，没有缩略图时显示视频图标。

通过“查看完整 AI 结果”打开详情。人工标签在输入框用逗号分隔；AI 标签取消勾选表示长期隐藏。重新识别更新 AI 结果，同时保留人工标签和隐藏选择。未识别、识别中、完成、失败在卡片内均有文字，不只依靠颜色。

使用 OpenList 原生搜索按钮或 Ctrl+K，在同一个输入框搜索文件名、AI 标签和中文简介。点击视频标签也打开原生搜索，并选中文件范围。输入 `#旅行 #日本` 要求同时具有两个标签；普通文字匹配标签或简介，多词也是 AND 关系，同义标签按管理规则归一。

AI 匹配直接显示在原生搜索弹窗中；同一个文件若已被原生文件名搜索找到，会在原结果旁补充标签和简介。搜索遵循原生当前目录及其子目录、文件范围和访问权限；在根目录搜索可跨挂载检索，文件夹范围不检索视频内容。文件链接仍打开原 OpenList 预览页。原生文件名搜索的分页保持原行为，AI 匹配通过弹窗内“继续查找”查看后续索引候选，不表示已经有可见匹配。AI 服务不可用时，文件名搜索仍可使用。

## 故障排查

| 问题 | 检查 |
|---|---|
| 原页面没有 AI 入口 | 查看同域 `/ai/health` 和 `/ai/assets/ai.js`；检查是否进入文件页、脚本是否被 CSP 禁止，以及前端选择器是否变更。 |
| 无管理员按钮 | 使用原 OpenList 管理员登录，`/api/me` 的 `role` 应为 2；过期 token 需重新登录。 |
| “无法连接 OpenList” | `OPENLIST_URL` 必须从容器 / Python 主机可访问；不可指回 AI 网关；检查 HTTPS 证书、代理和原站状态。 |
| 扫描凭据失效 | 优先配置 OpenList 长期管理员 API token；账号密码模式每小时刷新登录 token。不支持后台交互式二步验证码登录，请使用 API token。 |
| 模型请求失败 | 核对模型名、基础地址 `/v1`、密钥、余额和超时；点真实视觉测试。响应非 JSON 或模型输出不合规会被拒绝。 |
| 模型显示已连通，视频仍失败 | 模型测试只测试图像推理；还需检查媒体地址白名单、FFmpeg、网盘 Range、视频大小 / 流量 / 解码时长上限。 |
| 视频解码失败 | 进入原 OpenList 验证可以播放；检查签名过期和驱动返回的原始媒体 URL。播放列表、直播、DRM 和未知时长文件当前不支持。 |
| 网盘流量偏高 | 降低并发 / 帧数 / 流量上限，增大扫描间隔。某些容器索引位于文件尾，某些网盘不支持 Range，抽帧可能失败。 |
| 长视频缺少关键内容 | 增加帧数重新识别；抽样无法保证覆盖每个事件。当前没有自适应场景切分。 |
| 用户找不到管理员看到的结果 | 检查用户基础路径、目录密码、隐藏 / 访问权限和文件是否移动。结果不会借用管理员权限提供。 |
| 文件改名后人工标签没有跟随 | 该网盘可能没有提供可靠全文件哈希。首版只做强哈希复用，不靠大小猜测同一文件。 |
| 服务重启任务不见了 | 检查是否使用同一数据目录 / Docker 卷；使用 1 个 worker 和 1 个副本。 |
| 启动提示已有工作进程 | 同一个数据库只能运行一个调度器；OS 文件锁在进程结束后自动释放，不需要删除锁文件。 |
| 页面正常但视频旁仍未识别 | 确认目录在扫描范围、扩展名启用、没有排除，并查看历史记录。未索引视频不会通过页面浏览自动消耗模型额度。 |

错误记录不会保存模型密钥、管理员 token 或网盘签名 URL。底层第三方异常只记录类别；明确的服务错误记录可操作原因。排查 HTTP 认证问题时不要把 `.env`、`model-secret.json`、浏览器 token 或完整签名 URL 发到公开 issue。
